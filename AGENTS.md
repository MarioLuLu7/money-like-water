# AGENTS.md

## Project Rules

- During development, any requirement change, scope adjustment, architecture decision, or implementation plan change must be reflected in `DEVELOPMENT_PLAN.md`.
- Every development session must keep a concise log. The log should capture what changed, why it changed, and any important verification result, but it should not be verbose.
- Use the appropriate project skill at the appropriate time. Before applying a skill, read its `SKILL.md` and follow its instructions for the current task.
